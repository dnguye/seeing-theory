Hypothesis testing

Is the effect real, or could chance alone have produced it? A hypothesis test answers by asking how surprising the data would be if there were no effect at all.

In this chapter

    Null distributions and p-values

    A test begins with a null hypothesis H₀, the sceptical position: the coin is fair, the drug does nothing, the two groups have the same mean. Assuming H₀, we know the sampling distribution of our test statistic, the null distribution. Then we compute the statistic from the data and ask where it falls.

    The p-value is the probability, if H₀ were true, of a statistic at least as extreme as the one observed. A small p-value means the data would be surprising under H₀, which counts as evidence against it. By convention we reject H₀ when p falls below a preset significance level α, often 0.05. The p-value is not the probability that H₀ is true; it is the probability of the data given H₀, a distinction that Bayes' theorem in chapter 14 makes precise.

    Try this

    Set z = 1.8. Two-sided, p = 0.072: not significant at 0.05. Right-tailed, p = 0.036: significant. The same data, two answers, which is why the alternative must be chosen before looking at the data.

    Type I and Type II errors, and power

    A test can fail in two ways. Rejecting H₀ when it is true is a Type I error; its probability is exactly α, by construction. Failing to reject H₀ when it is false is a Type II error, with probability β. The power of a test, 1 − β, is the probability of detecting an effect that is really there.

    Power depends on three things: the size of the true effect δ, the noise σ, and the sample size n. Small effects in noisy data need large samples. Lowering α to guard against false alarms raises β, so the two errors trade off; only more data improves both. Planning a study means choosing n so that power is adequate, typically 80% or more, for the smallest effect worth finding.

    Try this

    With δ = 0.8, σ = 1 and n = 10, power is about 80%. Halve the effect to 0.4 and power drops to about 35%; find the n that brings it back to 80%. Then set δ = 0 and notice that the “power” equals α: with no effect, rejections are false alarms.

    The t-test in practice

    The most common test compares two group means. With samples of size n from each group, the two-sample t statistic divides the difference in means by its standard error, and under H₀ it follows a t distribution with 2n − 2 degrees of freedom. The lab runs whole experiments: it draws two groups, computes t and p, and keeps a histogram of the p-values across many repetitions.

    That histogram is the most instructive picture in this chapter. When there is no effect, p-values are uniform on [0, 1]: 5% of null experiments give p < 0.05, which is what α means. When there is an effect, p-values crowd toward 0, and the fraction below 0.05 is the power. Running many tests and reporting the ones that came out significant is how false discoveries are manufactured.

    Try this

    Set the true difference to 0 and run 1,000 experiments: the histogram is flat and about 5% are “significant”. Set it to 0.5 with n = 20 and the fraction climbs to roughly a third, so most real effects of that size go undetected. What n gets you to 80%?
